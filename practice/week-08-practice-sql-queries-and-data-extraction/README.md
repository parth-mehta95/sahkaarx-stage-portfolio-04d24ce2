# Practice SQL Queries and Data Extraction

## Task Brief
Develop SQL queries to extract key insights from the data.

## Scenario
As a Data Analyst, extract key insights from the dataset for a marketing report.

## Deliverables
- SQL queries
- Data extraction results

## Success Criteria
- Queries are efficient and well-documented.
- Results are accurate and relevant to the report.
- SELECT Queries: SQL queries return correct data.
- SELECT Queries: Queries filter data based on specified criteria.
