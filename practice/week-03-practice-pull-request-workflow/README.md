# Practice Pull Request Workflow

## Task Brief
Submit a pull request for the initial data ingestion script.

## Scenario
As a Data Analyst, submit your initial data ingestion script for review.

## Deliverables
- Merged Pull Request

## Success Criteria
- Pull request adheres to team standards.
- Code review feedback addressed.
- Data ingestion script integrated into main branch.
- Pull Requests: Pull request created with meaningful description.
- Pull Requests: Code review requested from a peer.
- Pull Requests: Pull request successfully merged.
