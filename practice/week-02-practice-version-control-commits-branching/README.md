# Practice Version Control: Commits & Branching

## Task Brief
Create a branch and commit changes to the capstone project.

## Scenario
As a Data Analyst, create a new branch for the data ingestion phase of the capstone project and commit initial files.

## Deliverables
- New branch created
- Initial commit on branch

## Success Criteria
- Branch name reflects purpose
- Commit message is clear and concise
- Commits: Commit messages follow best practices
- Branching: New branch created for data ingestion
